# Puzzle-RPG

Unity를 사용하여 개발한 퍼즐과 RPG 요소가 결합된 2D 게임 프로젝트입니다.
퍼즐을 통해 전투를 진행하는 방식의 게임을 구현하는 것을 목표로 제작했습니다.

* 개발 기간 : 2026.01.01 ~ 2026.02.24
* 개발 인원 : 6명 (팀 프로젝트)

## 주요 구현 시스템

### 데이터 관리 시스템

게임 내 몬스터 데이터를 CSV 파일로 관리하도록 구현했습니다.
CSV 데이터를 로드하여 Dictionary 형태로 저장하고, 필요할 때 빠르게 접근할 수 있도록 구성했습니다.
이를 통해 데이터 수정 및 관리가 용이하도록 설계했습니다.

### 저장 시스템

플레이어의 진행 상황을 저장하기 위해 JSON 기반 Save / Load 시스템을 구현했습니다.
게임 종료 후에도 플레이 데이터를 유지할 수 있도록 했으며,이후 기능 확장을 고려한 구조로 구조를 설계했습니다.

### UI 시스템

Unity UI를 활용하여 게임 메뉴 및 인터페이스를 구현했습니다.
버튼 이벤트와 UI 흐름을 관리하도록 구성하여 사용자 인터랙션이 자연스럽게 이루어지도록 설계했습니다.

### 사운드 시스템

BGM과 효과음을 관리하는 SoundManager를 구현했습니다.
볼륨 조절 기능을 추가하고 설정 값을 저장하여 게임을 다시 실행했을 때도 동일한 설정이 유지되도록 구현했습니다.

## 개발 과정에서 고려한 부분

게임 시스템을 기능별로 분리하여 구조적으로 관리할 수 있도록 설계했습니다.
Manager 패턴을 활용하여 각 시스템이 독립적으로 동작하도록 구현했으며,
데이터 관리와 저장 시스템을 직접 구현하여 게임의 확장성과 유지보수성을 고려했습니다.

또한 UI와 게임 로직을 분리하여 코드의 가독성과 관리 효율을 높이도록 노력했습니다.
